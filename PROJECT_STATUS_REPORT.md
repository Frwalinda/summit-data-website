## Main Files

- `package.json` defines three scripts: `build`, `lint`, and `dev`.
- `src/siteData.js` contains the company data, navigation, services, credibility signals, operating realities, projects, industries, approach steps, and capabilities.
- `src/styles.css` contains the full visual system and responsive layout.
- `src/main.js` controls the mobile navigation toggle.
- `scripts/build.js` renders the seven static pages, copies assets, writes `robots.txt`, and writes `sitemap.xml`.
- `scripts/lint.js` verifies required generated files, scans for banned/placeholder phrases, and checks basic HTML metadata and landmarks.
- `scripts/server.js` serves the built site locally for development.
